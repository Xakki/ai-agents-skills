# Deferred follow-up triage

Read the complete card and compare each item with current source, tests, configuration and worktree. Classify each as already complete, safe independent work, or blocked/ambiguous. A suggestion to consider a change and an external-environment investigation require a decision; do not silently choose. Implement only authorized, cohesive, specified work; preserve the card's stage and other changes unless a separate card or move was requested. Report partial status and unresolved decisions accurately, and avoid creating duplicate follow-up cards.
