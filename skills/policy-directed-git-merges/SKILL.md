# Policy directed git merges

Inspect merge bases, source and target scope before integration. Apply existing owner decisions to each conflict, preserve both compatible behaviors, regenerate derived artifacts through supported tools, and report unresolved material policy choices. A clean merge alone does not prove correct behavior.

Read [merge and parent review](../git-flow/references/merge-and-parent-review.md). For parent-by-parent and generated-artifact checks, use [merge parent evidence](../git-flow/references/merge-parent-evidence.md). Follow the user, project and runtime authorization for each operation; this skill does not grant additional authority.
