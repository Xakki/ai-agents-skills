# Read-only readiness review

Capture actual source and repository state, evidence commit scope and canonical card. Run available safe targeted lint and board status checks, confirming the intended card is selected and unique. Read the full acceptance and evidence together; require concrete results and explicit residual failures, skipped checks, dependencies and exclusions.

Verify current source and runtime claims against their actual evidence. A declared but unavailable capability is not admitted or healthy; where required, verify the fail-closed path when all capabilities fail. Separate directly reproduced local checks from recorded external claims, and do not replay live checks without authorization.

Return APPROVE only when stage, scope and required evidence agree without blockers; REQUEST CHANGES for a confirmed contradiction or omitted gate; BLOCKED when necessary evidence or access cannot be established. Report sources and limitations. Do not mutate the repository in a read-only review.
