# Decision handoffs

For each genuine material choice, state the task and current verified facts, distinguish stale text and unknowns, and present concrete options with benefits, risks, required authority, affected scope and deferred work. Recommend an option without inventing an unapproved contract. Record a later explicit decision and update the active acceptance criteria, preserving previous unanswered or timeout evidence as superseded history. Continue the already authorized phase without asking again; a design decision does not itself authorize live operations, release or publication.

Send external notifications only when explicitly authorized. Report completed outcomes and evidence; correct a prior success report if a later review rejects the candidate. If unrelated user work disappears, stop the affected pool, report it and pursue only exact authorized restoration; never reconstruct it from memory.
