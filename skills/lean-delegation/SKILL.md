# Lean delegation

Use the [teamlead delegation workflow](../teamlead/SKILL.md) to batch related reconnaissance, request a decision-focused digest with evidence, reuse available context when appropriate and include relevant known failure modes in briefs. Preserve required independent review and necessary details; token economy does not justify omitted evidence or unauthorized delegation.
