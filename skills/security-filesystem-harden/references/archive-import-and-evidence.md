# Archive acquisition, restoration and evidence

For an archive selected by an operator, define accepted source paths and types, validate arguments without shell interpolation, and acquire the content through the intended safe boundary. Where no-follow descriptor traversal is required, check each directory component and the final regular file using supported handle-relative operations, then validate and consume bytes from the same held object. Do not validate a host pathname and pass it as a container bind source as though container-side checks would undo host-side link resolution. Refuse rather than silently use an insecure fallback if the required platform protection is unavailable.

Bound archive input and decompression according to the task. Distinguish outer checksum verification from member inventory, member type and per-file content validation. With synthetic archives, test corrupt input, duplicate/unexpected members, links, altered bytes, final and ancestor replacement, malformed selectors and failed credentials. Recalculate a synthetic mutant's outer checksum when necessary to reach the intended deeper validator; never recalibrate a real accepted receipt. Ensure the downstream importer is not called when admission fails, and close every owned handle and child process on normal and error paths.

For evidence archives or cleanup of originals, first admit the exact roster and reader boundary; prove producer completion rather than inferring it from a closure filename. Check source identity before and after each admitted read and retain a unique manifest with member types, sizes and digests, a separate receipt, verified output digest, count convention and native outcomes. Preserve failed attempts as unqualified evidence according to the retention contract; do not apply ordinary replaceable-state cleanup to them. Run a separate read-only verifier after the writer exits and verify both the archive receipt and all members without extracting into the filesystem. A separate verifier invocation alone is not independent review.

Pin source/output identities and test a replaced parent so writes or deletion cannot reach a replacement directory. Delete originals only when separately authorized and only after independent verification of the approved set; reject unexpected files, pre-existing unrelated quarantine and identity drift. Recheck retained files and the archive before deletion, and verify exact target absence, retained objects and receipt after the mutator exits. Distinguish a confined helper from successful end-to-end archive or cleanup completion and durable retention.
