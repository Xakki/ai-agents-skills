# Source access recovery

When a requested source is unavailable, establish whether the failure is transient, rate-limited, access-controlled or due to missing permissions. Do not repeat the same failure without a new diagnostic reason, defeat an access or security control, or infer authorization to access restricted content.

Look for permitted official documentation, public excerpts, author-provided copies, alternative primary sources or archives when appropriate. Use the available retrieval interface and respect applicable access conditions. Verify the actual content and provenance rather than treating an HTTP success or generic landing page as the requested source.

Label archived material with its snapshot date and do not present it as current live content. Cite the actual supporting source and disclose a missing, stale or partial source when it matters. Third-party rendering and archival services may receive the requested URL; use them only within the task's privacy and authorization boundaries.
