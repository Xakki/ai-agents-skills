# Project, tenant and session isolation

Define the trusted authority source for each transport and the owning scope of each existing durable resource. A request-provided current ID can be a lookup hint; a durable row alone is not necessarily proof of a live caller's authority. Bind a live request to its actual server-owned session or equivalent context. Preserve documented handling of missing, legacy and unowned resources; never infer ownership from an attacker-controlled fallback. Explicitly authorized migrations are separate operations.

Map list, detail, search, history, descendants, resume, creation, update, delete, import/export, live RPC and aggregate paths. Apply the same authority before each read, mutation or live action, including counts, pagination backfill, fallback/recovery and empty cleanup. Rebind imported ownership only according to the target authority and authorized contract. Keep scope in durable records and every intermediate projection; ensure cache keys use the same resolved scope snapshot as their queries. For multiple profiles, resolve authority per profile, handle an unavailable profile explicitly and do not substitute another's scope.

When filesystem roots are part of a scope, use the documented canonicalization and symlink policy consistently. Do not assume every repository equates linked worktrees or subdirectories; test the project’s declared rule. A trusted scoped inventory must be selected at the query boundary, not via full-fleet read and later filtering. Request only necessary ownership and mount fields, not full environment-bearing objects. Validate selected-scope configuration even when its resource list is empty.

Test an own-scope success with foreign and unowned rows present, authenticated cross-scope attempts, missing authority, spoofed live IDs, counts and backfill, mutations, fallback paths and cache changes. Use realistic transport-bound fixtures and temporary stores when needed. Reconcile stale test doubles with the hardened contract; do not relax production authority or delete intentional negative controls to make old tests pass. A scoped result does not prove isolation of foreign resources that were never inspected.
