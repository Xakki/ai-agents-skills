# Git branch archival

Verify exact source, destination, checkout, worktrees, tip and recovery boundary. A branch rename does not switch the active checkout. Preserve paused work and historical blockers, avoid deleting dirty worktrees, and verify any separately authorized remote change.

Read [branch history and retirement](../git-flow/references/branch-history-and-retirement.md). For linked-worktree inclusion, use [content coverage](../git-flow/references/worktree-content-coverage.md). Follow the user, project and runtime authorization for each operation; this skill does not grant additional authority.
