# Post-repair verification

Follow the repair mode in [validation evidence](../validation-evidence/SKILL.md). Recheck the original failure when practical, distinguish focused from aggregate outcomes and examine shared-state or integration behavior where required. In a read-only review do not edit, stage, mutate or deploy; report unrun checks and unproven causes honestly.
