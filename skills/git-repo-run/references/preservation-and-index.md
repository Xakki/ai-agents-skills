# Preserving dirty work and the index

Before mutation, establish the current actor's authorized read/write boundary, repository and branch, HEAD, and pre-existing staged, unstaged and untracked state. Keep index, working bytes, modes and untracked content distinct. Capture enough permitted evidence to verify preservation; preserve secret or opaque paths using only their authorized metadata. A names-only Git command may still read working files, configuration or ignore rules, so honor stricter repository/native-reader boundaries. Exclude nested worktrees from broad scans unless explicitly authorized and do not treat the absence of gitlinks as proof a filesystem walk will avoid them.

Define an exact path and content allowlist, including both rename endpoints, permitted deletions and intended hunks in shared files. Preserve the actual pre-existing staged contents; explicit `git add` does not remove unrelated index entries. Parse status records without trimming leading XY columns and preserve both rename endpoints. Refresh authorized destination bodies after a helper stages an earlier rename. Inspect complete cached paths, blobs, modes and diff against the approved candidate before committing. Validate whole-file and selected-hunk scopes differently, and include relevant new files when testing or proving the candidate.

Do not use broad staging, reset, restore, clean or index replacement to make unrelated changes disappear. If a correction or index-only recovery is separately authorized, preserve native pre-repair evidence and recover only the established owned scope, keeping worktree bytes and foreign staging intact. A native access/security veto cannot be bypassed by another command or tool. An audit does not authorize staging or committing; a checkpoint does not establish acceptance.

Compare final actual commit and relevant index/worktree state with the entry baseline, not merely a path list or raw index checksum. Preserve concurrent changes; metadata drift alone does not prove their author or justify restoration. If protected work is damaged, stop, disclose it, and restore only from verified exact authorized evidence; do not reconstruct opaque or missing content from a summary.
