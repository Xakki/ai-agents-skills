# Brand review and publication

Review the complete requested artifact against its brief and recorded owner decisions. Distinguish proposed strategy from substantiated business statements. Check that promised guidelines, asset roles, source fidelity, backgrounds, typography, accessibility and interactions agree with actual delivered files; assess marks visually at their intended small and large uses, without relying on captions to prove recognition.

For interactive or web artifacts, check the applicable output contract, responsive behavior, keyboard/focus, labels, image alternatives and actual control/download behavior. Test self-containment and licensed fonts only when claimed or required. Record exact evidence and unrun checks; a static inspection is not a browser interaction test, and a technical pass does not by itself prove visual quality.

Return findings with the affected artifact, impact, evidence and smallest correction; separate blocking defects from optional refinements. Use an independent reviewer when required and actually available. A review verdict is not approval to publish or notify. If publication is authorized, use the requested interface and verify the actual resulting artifact before reporting completion. Preserve historical versions and the scope of each owner decision.
