# Promotion review checklist

- Capture branch, HEAD, baseline, staged/unstaged and untracked state, change summary and diff check. Repeat the snapshot before the verdict.
- Review the full card, decisions and execution log; verify canonical stage, any maintained status, unique active identity, approved scope, exclusions and ordering.
- Compare current scope against authoritative catalogs and adjacent cards: recompute applicable targets, special variants, security and routing boundaries, and ownership of deferred work. Never substitute an output category for an execution identity or weaken isolation and prerequisites.
- Identify unresolved questions and active statements contradicting the promotion; historical decisions must be clearly superseded. Check that evidence claims do not exceed their sources.
- Run safe authorized targeted and whole-board lint, diff checks and relevant static parsing. Report actual scope and failures; distinguish rerun evidence from prior execution logs. Do not start services, deploy, mutate data or use secrets without authorization.
- Give a read-only APPROVE or REQUEST CHANGES with exact locations, source evidence, impact and minimal corrections. One confirmed blocking contradiction is sufficient for REQUEST CHANGES even when lint passes.
