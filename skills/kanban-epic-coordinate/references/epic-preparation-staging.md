# Epic preparation and staging

Verify the actual branch and approved baseline before preparing an epic. Record its decision digest and dependency/acceptance evidence matrix before any separately authorized parent move; keep children in their existing stages unless their moves are separately authorized. Follow the project's branch conventions rather than imposing a universal branch name.

A mover can stage a rename before a later digest edit. If staging is authorized, explicitly stage the final destination content, inspect the complete staged path set and diff, and verify the committed card contains the intended digest and matrix. Run applicable targeted and board checks and report unrelated failures and residual changes honestly. Use only the repository's authorized trailer policy.
